# Changelog

## 1.1.0

- **Word → PDF without LibreOffice**: new built-in renderer (styles, lists, tables, images, headers / footers, page numbers).
- **Excel → PDF without LibreOffice**: built-in renderer that keeps colors, borders, merged cells and page setup.
- **Web page → PDF**: paste a web address, choose "as on screen", "one long page" or "print version". Uses the Chrome or Edge already installed.
- **Instant previews**: PDFs are displayed directly in your browser, without uploading them first.
- **Merge, organize, remove / extract pages and rotate run in your browser**: instant, nothing is sent.
- **Preview before downloading**, with the size before / after.
- **Real progress bar and queue**: each job runs separately, can be cancelled, and never blocks the others.
- **Privacy**: files are deleted from the server right after download (checked and shown), and leftovers are wiped at startup.
- **Protection** against oversized or malicious files (size, number of pages, compressed bombs, time limit).
- **Undo / redo** (Ctrl+Z / Ctrl+Y) in the editor and in Organize.
- **Full keyboard support**: reorder files and pages, place, move and resize elements in the editor.
- **5 languages** (English, French, Spanish, German, Italian), detected from your browser.
- **Installable app** (from the browser, or as a desktop application) with the cat mascot.
- Loading skeletons, animations, distinct icons, correct plurals.

## 1.0.0

- First version: 31 PDF tools, themes, English / French.
